## 📌 Project Description

Registration Assistant is a web-based assistant designed to help students with course registration, eligibility checking, and registration guidance.

The application provides a simple chatbot interface where students can ask questions about available courses and registration procedures. It also includes an eligibility checker based on the student's previous semester percentage.

## ✨ Features

- 🤖 Interactive chatbot
- 📚 Course information
- ✅ Course eligibility checking
- 📝 Registration guidance
- 🎓 Student registration assistance
- 📱 Simple and responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 Available Courses

The assistant provides information about:

1. Data Science
2. Python Programming
3. Web Development
4. Artificial Intelligence

## ✅ Eligibility Checking

Students can enter:

- Student name
- Selected course
- Previous semester percentage

The system checks the percentage and displays an eligibility result.

## 💬 Chatbot

The chatbot can respond to questions related to:

- Available courses
- Eligibility
- Registration process
- General greetings

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start interacting with the Registration Assistant.

No additional software or installation is required.
